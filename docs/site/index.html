OpenHiggsfield
by Transformaiton.com

A studio for one-minute character films. Pick a cast, review six scenes and the estimate, then render with API keys from accounts you control.

View on GitHub ↗ Install guide ↗

Your cast

50 included characters, or a PNG, JPG, or WebP you upload.

Your script

Six scenes, about one minute. Edit the words, then read the estimate.

Your film

A 720p MP4 when you approve a render on your fal or Higgsfield balance.

Run it yourself.

Node.js 24 and FFmpeg, or Docker Compose. Sign-in email uses your Resend account. Rendering uses your fal or Higgsfield account.

Install and self-hosting ↗
Using the studio ↗ 
git clone https://github.com/Transformaiton/OpenHiggsfield.git
cd OpenHiggsfield
npm ci
npm ci --prefix apps/story-studio
npm run dev
# Second terminal:
npm --prefix apps/story-studio run dev
